# 技術スタック選定

本ドキュメントでは、旅行計画・割り勘スマホアプリ「TripApp (仮称)」を、**Nuxt** をベースに **完全無料（追加費用なし）** でスマートフォンアプリとして動作させるための技術スタックと構成案を定義します。

---

## 1. 推奨技術スタック構成

ユーザー認証、リアルタイムの共同編集、データベース管理、およびアプリ化をすべて無料枠で実現するため、以下の構成を提案します。

```mermaid
flowchart TD
    subgraph クライアント (モバイルアプリ)
        Nuxt[Nuxt 3 <br> Vue 3 / TS]
        Tailwind[Vanilla CSS / Tailwind]
        AppType{アプリ化手法}
        Nuxt --> AppType
        AppType -->|手軽・完全無料| PWA[PWA化 <br> ホーム画面に追加]
        AppType -->|ネイティブ化| Cap[Capacitor <br> iOS / Androidアプリ]
    end

    subgraph バックエンド / インフラ (すべて無料枠)
        Supa[(Supabase Free Plan <br> PostgreSQL)]
        Host[Cloudflare Pages / Vercel]
    end

    Nuxt <-->|Supabase SDK| Supa
    PWA <-->|ホスティング| Host
```

### 1.1. 技術要素一覧

| 役割 | 選定技術 | 無料枠の範囲 / メリット |
| :--- | :--- | :--- |
| **フロントエンド** | **Nuxt 3** (Vue 3 / TypeScript) | 高速なViteビルド、SEO・PWAプラグインの充実、SPA化が容易。 |
| **スマホアプリ化** | **PWA** (Progressive Web App) <br> もしくは **Capacitor** | ・**PWA**: Webアプリをホーム画面にインストール。開発・維持費ともに**完全無料**。<br>・**Capacitor**: ネイティブアプリ化。ストア公開せずに自分の端末へ直接インストールする分には**完全無料**。 |
| **データベース** | **Supabase (PostgreSQL)** | 無料枠で 500MB の容量。リレーショナルDBなので割り勘のデータ設計と相性抜群。 |
| **リアルタイム同期** | **Supabase Realtime** | スケジュールが変更された際の、メンバー間でのリアルタイム反映を完全無料で実現可能。 |
| **ユーザー認証** | **Supabase Auth** | メールアドレス・パスワード認証が無料。OAuth（Google等）も無料。 |
| **ホスティング** | **Cloudflare Pages** または **Vercel** | 無料枠が非常に大きく、商用目的でなければAPIやWebのホスティングは完全無料。 |

## 2. 「お金をかけない」スマホアプリ化のロードマップ

Apple Store や Google Play ストアにアプリを公式公開する場合、年間ライセンス料（Appleは年$99、Googleは初回$25）が必要になります。
これを回避して **「1円も払わずにスマホアプリとして使う」** ために、以下の2つのアプローチを採用します。

### アプローチA：PWA (Progressive Web App) 化 【最も推奨】
Webサイトとして公開したものを、スマホのブラウザ（SafariやChrome）から「ホーム画面に追加」することで、本物のアプリのように動作させます。

* **特徴**:
  * アドレスバーやブラウザの操作ボタンが消え、全画面で「ネイティブアプリ」のように起動する。
  * オフライン動作やキャッシュ管理が可能。
  * プッシュ通知も送信可能（iOS/Android対応）。
  * 開発・公開にかかる費用は **完全無料（0円）**。

### アプローチB：Capacitor によるハイブリッドアプリ化 (身内用デバッグビルド)
HTML/CSS/JS（Nuxtの成果物）を iOS/Android のネイティブアプリパッケージ（ipa / apk）に変換します。

* **特徴**:
  * ストアを通さず、ローカル開発環境（XcodeやAndroid Studio）から自分のスマートフォンに直接ケーブルを繋いでアプリをインストールする。
  * **完全無料** で実機で本物のネイティブアプリとして動かせる。
  * 配布は自分や友人の範囲（テストデバイス登録）に限られるが、旅行に行くメンバーにだけインストールして使ってもらう用途には最適。

## 3. バックエンドに「Supabase」を採用する理由

Nuxt 3 との親和性が非常に高く、フロントエンドエンジニアがサーバーを用意せずにバックエンドを構築できる BaaS (Backend as a Service) です。

1. **リレーショナルデータベース (PostgreSQL)**:
   - 割り勘アプリは「ユーザー」「旅行」「支払」「対象者」という複雑なリレーションが発生するため、Firebase (NoSQL) よりも PostgreSQL (SQL) の方がバグが発生しにくく、計算クエリが容易です。
2. **リアルタイム同期機能**:
   - `supabase-js` を使うことで、誰かがスケジュールを追加した瞬間、他のメンバーの画面も自動で書き換わる仕組みを一行のコードで実装できます。
3. **完全無料**:
   - ユーザー認証、DB容量500MBまで無料で、今回の規模の旅行アプリであれば無料枠の上限を超えることはまずありません。

## 4. Nuxt 3 での実装方針（SPA化）

スマホアプリとしてスムーズに動かす（画面遷移のアニメーションや動作を滑らかにする）ため、Nuxt 3 は **SPA（Single Page Application）モード** でビルドします。

```typescript
// nuxt.config.ts の設定イメージ
export default defineNuxtConfig({
  ssr: false, // SPAモードに設定（Capacitor/PWAで高速動作）
  modules: [
    '@nuxtjs/supabase', // Supabaseモジュール
    '@vite-pwa/nuxt'     // PWA自動生成モジュール
  ],
  supabase: {
    redirect: true, // ログインしていない場合はログイン画面に自動リダイレクト
  }
})
```
