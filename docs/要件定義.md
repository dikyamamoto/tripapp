# 要件定義

本ドキュメントでは、旅行計画・割り勘スマホアプリ「TripApp (仮称)」に必要な機能要件および非機能要件を定義します。

---

## 1. 機能要件

### 1.1. ユーザー管理機能
* **アカウント作成 / ログイン**:
  * メールアドレスとパスワードによる認証を行う。
* **プロフィール設定**:
  * アプリ内で他のメンバーから識別しやすいよう、表示名（ニックネーム）を設定・変更できる。

### 1.2. 旅行グループ管理機能
* **旅行の新規作成**:
  * ホストが旅行を作成できる（タイトル、開始日、終了日、カバー画像など）。
* **メンバー招待**:
  * 旅行ごとにユニークな「招待コード」を発行できる。
* **旅行への参加**:
  * 他のユーザーが招待コードを入力することで、その旅行のメンバーとして参加できる。
* **メンバー一覧表示**:
  * 旅行に参加している全メンバーの表示名を確認できる。

### 1.3. 旅行計画（スケジュール）共同編集機能
* **タイムライン表示**:
  * 日程別（1日目、2日目...）に、予定を時系列（タイムライン形式）で一覧表示する。
* **予定の追加・編集・削除**:
  * 項目名（例：「羽田空港集合」「〇〇で昼食」「ホテルチェックイン」）
  * 開始時間・終了時間
  * 場所・メモ（住所やマップのURLなど）
* **リアルタイム同期**:
  * 他のメンバーが編集したスケジュールが、ページのリロードなしで即座に他のメンバーの画面に反映される。

### 1.4. 割り勘（経費精算）機能
* **出費の記録**:
  * 支払者（誰が支払ったか）
  * 金額（いくら支払ったか）
  * 費目/内容（何のために支払ったか：例「レンタカー代」「居酒屋」）
  * 対象メンバー（誰のための出費か：全員、または特定のメンバーを選択可能）
* **出費履歴の管理**:
  * 登録された出費の一覧を表示し、後から編集や削除ができる。
* **自動割り勘計算**:
  * 登録されたすべての出費情報から、各メンバーの純貸借（貸し借りの合計）を計算し、「誰が誰にいくら払えば最も効率的（送金回数が最小）か」を自動算出する。

---

## 2. 非機能要件

### 2.1. 操作性・デバイス対応
* **モバイルファースト**:
  * スマートフォン端末（iOS/AndroidのWebブラウザ）での操作に最適化されたレスポンシブデザインとする。
* **シンプルで直感的なUI**:
  * 旅行中に移動しながらでも、迷わず素早く入力・確認できるレイアウト。

### 2.2. パフォーマンス・信頼性
* **データの整合性**:
  * 複数人が同時にスケジュールや出費を編集しても、競合が発生しにくく、最新のデータが保たれること。
