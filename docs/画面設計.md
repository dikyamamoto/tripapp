# 画面設計

本ドキュメントでは、旅行計画・割り勘スマホアプリ「TripApp (仮称)」に必要なすべての画面（ビュー）、画面遷移、および各画面の構成要素について定義します。

---

## 1. 画面一覧

アプリに必要な画面は、モーダルやサブ画面を含めて以下の **合計 13 画面（ビュー）** で構成されます。

| 画面ID | 画面名 (日本語) | 画面名 (英語/識別子) | 主な役割 |
| :--- | :--- | :--- | :--- |
| **01** | LP / スプラッシュ画面 | `SplashPage` | アプリ起動時の案内と認証への入り口 |
| **02** | 新規会員登録画面 | `SignUpPage` | ニックネーム、パスワードでの登録 |
| **03** | ログイン画面 | `SignInPage` | 登録済みアカウントでのログイン |
| **04** | マイ旅行一覧画面 | `TripListPage` | 自分が作成・参加している旅行の一覧表示（ホーム） |
| **05** | 旅行作成画面 (モーダル) | `CreateTripPage` | 新規旅行（タイトル、日程、カバー画像）の作成 |
| **06** | 旅行参加画面 (モーダル) | `JoinTripPage` | 招待コードを入力して既存の旅行グループに参加 |
| **07** | 旅行詳細：スケジュール | `TripScheduleTab` | 旅行日程（タイムライン）の閲覧・管理（メインタブ1） |
| **08** | 予定追加・編集画面 (モーダル) | `AddEditEventPage` | タイムラインへの予定の追加と変更 |
| **09** | 旅行詳細：割り勘・経費一覧 | `TripExpenseTab` | 支払履歴の一覧と個人の収支サマリー表示（メインタブ2） |
| **10** | 出費登録・編集画面 (モーダル) | `AddEditExpensePage` | 支払内容、金額、支払者、割り勘対象者の登録 |
| **11** | 自動清算結果画面 | `SettlementPage` | 送金回数を最小化した清算ルートの提示と実行 |
| **12** | 旅行詳細：メンバー一覧・招待 | `TripMembersTab` | メンバー確認と招待コード・招待リンクのコピー（メインタブ3） |
| **13** | プロフィール設定画面 | `ProfileSettingsPage` | ユーザーの表示名、アイコン設定、ログアウト |

## 3. 各画面の詳細仕様

### 3.1. LP / スプラッシュ画面 (`SplashPage`)
* **目的**: アプリの認知および認証画面への誘導
* **構成要素**:
  * アプリのロゴとキャッチコピー
  * 「新しくアカウントを作る」ボタン ➔ 新規会員登録画面へ
  * 「ログインする」ボタン ➔ ログイン画面へ

### 3.2. 新規会員登録画面 (`SignUpPage`)
* **目的**: 新規ユーザーアカウントの作成
* **構成要素**:
  * 表示名（ニックネーム）入力フォーム
  * パスワード入力フォーム
  * パスワード（確認用）入力フォーム
  * 「アカウントを作成する」ボタン
  * 「すでにアカウントをお持ちの方（ログイン）」リンク ➔ ログイン画面へ

### 3.3. ログイン画面 (`SignInPage`)
* **目的**: 既存ユーザーのログイン認証
* **構成要素**:
  * 表示名（ニックネーム）入力フォーム
  * パスワード入力フォーム
  * 「ログイン」ボタン
  * 「アカウントをお持ちでない方（新規登録）」リンク ➔ 新規会員登録画面へ

### 3.4. マイ旅行一覧画面 (`TripListPage`)
* **目的**: 参加中・計画中の旅行を選択するホーム画面
* **構成要素**:
  * ヘッダー: アプリ名、プロフィールアイコン（タップでプロフィール設定画面へ）
  * 旅行一覧（カード形式のリスト）:
    * カバー画像
    * 旅行タイトル
    * 日程（例：「2026/08/10〜2026/08/12」）
    * 参加メンバー数とメンバーの丸型アイコン（アバター）
  * フローティングまたは下部のアクションボタン:
    * 「＋ 新しく旅行を計画」ボタン ➔ 旅行作成画面へ
    * 「招待コードで参加」ボタン ➔ 旅行参加画面へ

### 3.5. 旅行作成画面 (`CreateTripPage`) ※モーダル表示を想定
* **目的**: 新しい旅行イベントの登録
* **構成要素**:
  * 入力フォーム:
    * 旅行タイトル（例：「夏の北海道旅行」）
    * 開始日・終了日（カレンダーピッカー）
    * カバー画像（プリセット画像からの選択、またはアップロード）
  * 「作成する」ボタン ➔ 作成後、該当の旅行詳細画面へ遷移
  * 「キャンセル」ボタン ➔ マイ旅行一覧画面へ戻る

### 3.6. 旅行参加画面 (`JoinTripPage`) ※モーダル表示を想定
* **目的**: 招待コードを使用した既存旅行への加入
* **構成要素**:
  * 招待コード入力フォーム（英数字6桁など）
  * 「参加する」ボタン ➔ 参加成功後、該当の旅行詳細画面へ遷移
  * 「キャンセル」ボタン ➔ マイ旅行一覧画面へ戻る

### 3.7. 旅行詳細：スケジュール (`TripScheduleTab`)
* **目的**: タイムラインを用いた旅行計画の共有と共同編集
* **構成要素**:
  * 旅行タイトルと日程（ヘッダーに常時表示）
  * **日付タブ**: 1日目、2日目、3日目... または「全日程」の切り替え
  * **タイムラインビュー**:
    * 縦方向のタイムライン線と、各予定が時間順に並んだカード
    * 各予定カードの表示項目: 時間（例「10:00〜11:30」）、予定名、場所、メモ、編集ボタン
  * **「＋ 予定を追加」ボタン** ➔ 予定追加・編集画面へ

### 3.8. 予定追加・編集画面 (`AddEditEventPage`) ※モーダル表示を想定
* **目的**: スケジュール項目の新規登録および変更
* **構成要素**:
  * 予定名入力フォーム
  * 日程選択（旅行の全日程からドロップダウン）
  * 開始時間・終了時間（タイムピッカー）
  * 場所・住所・マップURLの入力フォーム
  * メモ（持ち物やリンクなど）
  * 「保存する」ボタン / 「削除する」ボタン（編集時のみ） / 「キャンセル」ボタン

### 3.9. 旅行詳細：割り勘・経費一覧 (`TripExpenseTab`)
* **目的**: 旅行中の出費の把握と支払履歴の管理
* **構成要素**:
  * **サマリーエリア**:
    * グループ全体の総出費額（例：「総出費: 56,000円」）
    * ユーザー自身の現在の収支（例：「あなたは現在 +3,500円 もらえます」または「あなたは現在 -4,200円 支払う必要があります」）
  * **アクションエリア**:
    * 「＋ 出費を記録する」ボタン ➔ 出費登録・編集画面へ
    * 「清算する（送金ルートを見る）」ボタン ➔ 自動清算結果画面へ
  * **出費履歴リスト（時系列降順）**:
    * 各履歴の表示項目: 日付、内容（例「レンタカー代」）、支払った人、金額（例「¥12,000」）、割り勘の対象者（アバター表示）

### 3.10. 出費登録・編集画面 (`AddEditExpensePage`) ※モーダル表示を想定
* **目的**: 立て替えた支払いの詳細情報を登録する
* **構成要素**:
  * 出費内容入力フォーム（例：「夕食代」など）
  * 金額入力フォーム（半角数字）
  * 支払日（カレンダーピッカー）
  * 支払者選択（グループのメンバーから1人選択、デフォルトは操作中のユーザー）
  * 対象メンバー選択（グループの全メンバーから、この出費を割り勘にする対象を選択。デフォルトは「全員チェック」）
  * 「登録する」ボタン / 「削除する」ボタン（編集時のみ） / 「キャンセル」ボタン

### 3.11. 自動清算結果画面 (`SettlementPage`)
* **目的**: 送金回数を最小限にした効率的な精算方法の提示
* **構成要素**:
  * **精算ルートのリスト**:
    * 例：「**Aさん** から **Bさん** へ **3,500円** 送金してください」という分かりやすいテキスト表示
  * **送金完了チェック**:
    * 送金が完了したルートに対して「送金完了にする」ボタン
  * 「旅行を完了（清算クローズ）する」ボタン（すべての送金が完了した後にホストが押下可能。これ以降は出費の編集ができなくなる）
  * 「戻る」ボタン ➔ 割り勘・経費一覧画面へ

### 3.12. 旅行詳細：メンバー一覧・招待 (`TripMembersTab`)
* **目的**: 旅行グループのメンバー管理と新規招待
* **構成要素**:
  * **招待セクション**:
    * 招待コード（例：`TRIP88`）と「コピー」ボタン
    * 招待用リンクURLと「コピー」ボタン
  * **メンバーリスト**:
    * 各メンバーのアイコン、表示名
    * 「ホスト（作成者）」などのバッジ
  * 「グループから抜ける」ボタン（メンバー自身がグループを退退する用）

### 3.13. プロフィール設定画面 (`ProfileSettingsPage`)
* **目的**: アカウント情報の管理
* **構成要素**:
  * プロフィール画像（アバター）設定・変更
  * 表示名（ニックネーム）変更フォーム
  * パスワード変更フォーム
  * 「変更を保存する」ボタン
  * 「ログアウト」ボタン
  * 「戻る」ボタン ➔ マイ旅行一覧画面へ
